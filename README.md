# Ports Launcher Extras

Extra files for [Ports Launcher](https://github.com/Nyaldee/Ports-Launcher): small tools, plus game configurations, launcher scripts and patches. They live here, as release assets, so the launcher repository stays light.

> [!IMPORTANT]
> **This repository ships no game files, ROMs, ISOs, BIOS, or any other copyrighted asset whatsoever.**

## Releases

| Release | Content |
|---|---|
| [`tools`](https://github.com/Nyaldee/Ports-Launcher-Extras/releases/tag/tools) | Standalone tools. |
| [`games`](https://github.com/Nyaldee/Ports-Launcher-Extras/releases/tag/games) | Per-game configurations, scripts and patches. |

Both releases use a fixed tag. Files are replaced in place when they change, so links stay the same:

```
https://github.com/Nyaldee/Ports-Launcher-Extras/releases/download/<tag>/<file>
```

## Usage

Ports Launcher downloads what a port needs on its own when you install it (the `extra` field in its catalog). You can also download any file by hand from the release pages.
